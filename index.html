CASO DE ESTUDIO

Vue Product Showcase

Análisis del proceso de desarrollo de una aplicación web construida con Vue 3.

🎯 Objetivo

Desarrollar una Single Page Application (SPA) capaz de presentar un catálogo de productos obtenido desde una API REST, permitiendo a los usuarios explorar productos y navegar entre diferentes vistas de manera clara y sencilla.

🧩 Desafío principal

El principal desafío fue integrar diferentes funcionalidades dentro de una aplicación Vue 3, manteniendo una estructura organizada y utilizando componentes reutilizables.

💡 Solución propuesta

Se construyó una aplicación utilizando Vue 3 y Vite, separando la interfaz en componentes y utilizando Vue Router para la navegación entre las diferentes vistas del catálogo.

🛠️ Tecnologías utilizadas

Vue 3 JavaScript Vite Vue Router REST API Cypress ESLint Prettier Git & GitHub

🧠 Principales aprendizajes

El proyecto permitió fortalecer mis conocimientos en Vue 3, componentes, consumo de APIs REST, navegación entre vistas y organización de proyectos Front-End.

📊 Resultados

La aplicación logró integrar correctamente una API REST y presentar un catálogo funcional de productos mediante una arquitectura basada en componentes.
